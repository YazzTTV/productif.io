# TikTok organique - Lead gen Productif

Date: 2026-08-24

## Contrainte

En organique TikTok, on ne peut pas mettre un lien App Store different directement sous chaque video, sauf via certains modules comme:

- lien en bio
- formulaire "Obtenir des prospects"
- lien produit, surtout adapte a TikTok Shop / e-commerce
- commentaire + envoi manuel du lien

Pour Productif, le bon canal a tester en priorite est "Obtenir des prospects", pas "Lien de produit".

## Setup recommande

Pour chaque video importante, creer un formulaire TikTok dedie avec un code contenu.

Exemples:

- `Productif - C10`
- `Productif - C11`
- `Productif - C12`

Le code `Cxx` identifie la video ou le concept creatif.

## Formulaire TikTok

Nom du formulaire:

```text
Productif - C10
```

Titre:

```text
Recois le lien du Mode Examen
```

Description:

```text
L'app pour bloquer les distractions pendant tes revisions et lancer des sessions de focus de 25 minutes.
```

Champ demande:

```text
Email
```

CTA:

```text
Recevoir le lien
```

Politique de confidentialite:

```text
https://productif.io/privacy-policy
```

## CTA a mettre dans les videos

Texte oral ou overlay:

```text
Si tu veux tester, le formulaire est juste sous la video.
```

Caption possible:

```text
Le lien est sous la video. Teste 25 min sans TikTok pendant tes revisions.
```

Variante:

```text
J'ai mis le lien sous la video, mets ton mail et tu recois l'acces.
```

## Lien en bio

Garder un lien en bio en fallback:

```text
https://productif.io/mode-examen?utm_source=tiktok&utm_medium=organic&utm_campaign=vague2&utm_content=bio
```

Le lien en bio est moins propre pour attribuer plusieurs videos en meme temps, mais il capture les personnes qui vont chercher Productif manuellement.

## Tracking attendu

Le funnel vise:

```text
Video C10 -> formulaire TikTok C10 -> email lead -> OneLink C10 -> install -> signup -> onboarding -> achat
```

Le plus important est de ne pas melanger les codes: un formulaire `Productif - C10` doit envoyer un lien avec `utm_content=C10`.

## Decision

Pour les prochains posts organiques:

1. Ne pas utiliser "Lien de produit" pour Productif.
2. Utiliser "Obtenir des prospects" sur les videos importantes.
3. Nommer chaque formulaire avec un code video.
4. Exporter ou synchroniser les leads TikTok.
5. Envoyer aux leads le OneLink Productif avec le meme code `utm_content`.
